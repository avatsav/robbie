    Connect the picture to the code—and what’s still missing
    Implemented under tests
    • validate_tool_exchanges refuses missing, duplicate or mismatched results. It never replays a tool.
    • find_cut walks backward through supplied size estimates. It returns an index or no useful cut; it does not keep a live tail buffer.
    • prepare_summary makes the historical text shown above. Each tool result is limited to 2,000 Unicode characters with an omission count. Other content must fit in full.
    • compact_history requests a candidate through the shared HTTP client, with no tools, no generated cache markers and a supplied output cap. It requires a normal end, nonblank text, no tool calls and an estimated size reduction before changing the summary and raw tail together.
